# OneBe SLIDE

OneBeのロゴを使用したHTML/CSSスライド共有サイト。GitHub Pages用の静的アプリです。

## 画面

- `#/deck/:id` — 登録した資料のスライド閲覧画面
- `#/library` — 資料一覧、検索、カテゴリ、お気に入り、管理
- `#/new` / `#/edit/:id` — 登録・編集、プレビュー、資料書き出し

ログイン画面はありません。トップページは資料ライブラリです。初期サンプル資料はすべて削除し、公開資料0件で開始します。

## 機能

HTML・ZIP・HTML貼り付けでの登録、ページ送り、矢印キー操作、サムネイル、全画面表示、16:9・A4縦・A4横、混在ページサイズのPDF生成、共有URL、埋め込み、お気に入り、資料編集、パッケージ書き出しに対応しています。

画面の登録データはIndexedDB、お気に入りはlocalStorageに保存されます。登録しただけで別のブラウザには公開されません。ブラウザのサイトデータを消去すると登録資料も消えます。必要な資料はZIPで書き出してください。

GitHub Pagesは公開配信です。「社内限定」などの認証によるアクセス制御や、全ユーザー共通のアップロード保存先は実装していません。資料の公開は以下の手順でリポジトリへ反映します。

## HTMLの作り方

1ページを `.slide` または `[data-slide]` 要素で囲みます。Reveal形式の `.slides > section` にも対応します。どれもなければHTML全体を1ページとして読み込みます。

```html
<style>
  .slide { width:1280px; height:720px; padding:64px; box-sizing:border-box; }
</style>
<section class="slide" data-title="タイトル">
  <h1>プレゼンテーション</h1>
</section>
<section class="slide" data-format="A4縦" data-title="A4資料">
  <h1>A4ページ</h1>
</section>
```

標準サイズは16:9=1280×720、A4縦=794×1123、A4横=1123×794です。ページ個別に `data-format="A4縦"` を指定できます。CSSは埋め込み、またはZIPにHTMLと相対パスのCSS・画像・フォントを同梱します。ZIPには `index.html` を含めるか、各ページのHTMLをファイル名順に格納します。最大25MB、100ページまで。外部素材は配信元のCORS設定によってPDFに表示されない場合があるため、ZIPに同梱する方法を推奨します。JavaScriptやフォームは取り込み時に除去し、iframe内で静的HTML/CSSを表示します。PDFは各ページを画像化するため、文字検索はできません。

## 公開資料の追加

1. 登録・編集画面の「資料を書き出す」でZIPをダウンロード。
2. ZIP内の `deck.json` を `public/decks/index.json` の配列に追加。`id` は他の資料と重複させないこと。
3. `npm ci`、`npm run build` を実行。
4. ソースと `docs/` の変更をmainブランチへコミット。Pagesが更新されます。

公開された追加資料はライブラリに表示され、URL共有と埋め込みが利用できます。画像などをdata URLで同梱すると移動後も再現できます。公開資料の編集はコピーとしてブラウザに保存されます。

## 開発・公開

```sh
npm ci
npm run dev
npm run build
```

Node.js 22以上推奨。ビルド先は `docs/`。GitHub Pagesを `Deploy from a branch` / `main` / `/docs` に設定します。相対アセットパスとハッシュルーティングを使うため、リポジトリ名付きURLでも全ページを再読み込みできます。

## UI・素材

公式OneBeロゴはユーザー指定のGoogle Drive素材を使用。ナビゲーション、フォーム、閲覧画面はHTML/CSSで実装しています。初期サンプル資料と専用画像は削除済みです。登録画面でダウンロードできるHTMLは、内容を入力するための空のひな形です。

## 確認内容

ライブラリ検索、HTML貼り付けによる取り込み、スライド分割、A4ページ認識、ブラウザ保存と再読み込み、全画面表示と終了、PDFダウンロード（16:9とA4縦の混在）をブラウザで確認。生成PDFのMediaBoxで各ページ寸法を検証しています。
